## 地址，指针，引用与借用

- **地址**：无论一个数据存放在堆还是栈，它都对应一个内存编号，这个编号就是这个数据的地址。
- **指针**：指针是一种**数据类型**，它表示对一个数据在内存中位置的指向，指针宏观来看就是指向数据的地址，但包含了指向数据的类型等更多信息。
- **引用**：引用也是一种指针，但额外受到Rust借用规则、有效性和生命周期等约束。

`&` 引用运算符可以用来获取数据的地址。

```rust
fn test_reference() {

    let x = 233;

    let x = &x;  // 创建一个引用

    let p: *const i32 = x as *const i32;  // 将引用转换为指针

    println!("p的地址：{:p}", p);   //  0x2efcf7f914

    println!("x的地址：{:p}", x);   //  0x2efcf7f914，引用和指针一样指向x变量所在的地址

}
```

**传递数据的引用不会引起数据所有权的移动**，这种机制就是Rust的借用机制。


## 解引用

`*` 运算符可以用来解引用。解引用是会造成所有权移动的，这点要和引用区分。
